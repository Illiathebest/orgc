# Журнал апаратних проблем стенда

Журнал проблем із залізом лабораторії (pve-a — ноут/HQ, pve-b — ПК). Формат запису наведено в кінці.

## Залізо (актуальне)

- pve-a (ноутбук, HQ): Proxmox VE 9.2, `192.168.1.40`. CPU Intel Core i3-5005U (Broadwell, тримає до 16 ГБ). RAM 16 ГБ (8+8, обидва слоти). Диск 128 ГБ. 2 ядра 2 ГГц. Роль: control plane (ctrl-01: GitLab CE + Runner; mon-01 знову можливий). «Завжди увімкнений» через WoL. Фізичний стан: open-bench, корпус зруйновано, Wi-Fi знято, тому лише дротовий Ethernet (HW-004); старт замиканням падів power-on на материнці (HW-005).
- pve-b (ПК, філія): 32 ГБ RAM, 1.5 ТБ SSD (+1 ТБ NVMe 2026-06-11), Windows + VMware Workstation → nested Proxmox. Роль: containerlab, цільові сервери, Wazuh, runner-b. Вмикається на час експериментів.

## Активні проблеми

Немає. Усі апаратні інциденти 2026-06-14 закриті (стислий архів нижче; повна діагностика — в git history).

## Закриті проблеми (стислий архів)

- HW-001 — WoL після повного знеструмлення pve-a. Resolved (операційно). WoL живиться standby-струмом NIC; рішення: батарею залишено + AC (вбудований UPS). Залишкове обмеження: якщо блекаут довший за автономність, remote-wake залежить від збереження налаштувань у BIOS. Опційний хардненг (`post-up /sbin/ethtool -s <iface> wol g` у `/etc/network/interfaces`) відкладено за рішенням.
- HW-002 — 3 блимання Caps Lock, «мертвий» слот RAM 2. Fixed. Справжня причина — аномально тугий слот: планка недосаджувалась навіть з уявним клацанням; після сильнішої посадки 16 ГБ (8+8) працюють. Планки еквівалентні (ADATA 693374-005 ≡ HP/Kingston 863492-001, обидві 8 ГБ DDR3L-1600 2Rx8), i3-5005U тримає 16 ГБ. Урок: не поспішати з висновком про апаратну відмову.
- HW-003 — кулер не крутить + попередження BIOS. Fixed. Збитий роз'єм вентилятора; повторне під'єднання оживляє. Рецидив через затиск рештками корпусу, тому в OEM-корпус не збирати.
- HW-004 — корпус зруйновано → open-bench. Accepted (стоп-гап). Тільки дротовий Ethernet; плата на непровідній підкладці; не рухати/не гнути; радіатор щільно прикручений; керування через Proxmox web/SSH.
- HW-005 — відірвано шлейф кнопки живлення. Resolved (workaround). Старт коротким замиканням падів power-on на материнці; далі вмикання через WoL. Фізична кнопка не потрібна.

## Відкриті питання

- Кандидат-ADR: міграція HQ з ноута на вживаний micro-PC (DDR4 + vPro/AMT + multi-disk). Підстава: каскад HW-002…005, потреба гарантованого remote-wake і 6 ядер замість 2. Поки pve-a в open-bench як стоп-гап.
- pve-a знову має 16 ГБ, тому рішення з M0 (п. 1) дійсне: повернути ctrl-01 до 8 ГБ та підняти mon-01 на pve-a.

## Інші відкриті апаратні питання

- (M3) Фізичний MikroTik і легальні Cisco-образи: апаратно-ліцензійне питання, див. ADR-003.
